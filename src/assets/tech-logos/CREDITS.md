# Technology logo sources

Official marks, used unaltered apart from the colour or clean-up noted below. Each logo is a trademark of its owner.

- **Devicon** (MIT licence, https://devicon.dev): every logo in this folder unless listed below.
- **Simple Icons** (CC0, https://simpleicons.org): `snowflake.svg`, `bigquery.svg`, `openai.svg` (v11.0.0) and `langchain.svg` (v13.21.0). Simple Icons ships single-colour marks, so each file's `fill` is set to the brand colour Simple Icons lists for it (#29B5E8, #669DF6, #412991, #1C3C3C).
- **Wikimedia Commons** (public domain): `excel.svg` (File:Microsoft_Office_Excel_(2019–2025).svg) and `powerbi.svg` (File:New_Power_BI_Logo.svg). Neither icon set carries Microsoft's product marks. The Illustrator export header and metadata were removed; the artwork is unchanged.
