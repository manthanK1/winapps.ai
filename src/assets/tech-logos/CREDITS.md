# Technology logo sources

Official marks, used unaltered apart from the colour noted below. Each logo is a trademark of its owner.

- **Devicon** (MIT licence, https://devicon.dev): every logo in this folder unless listed below.
- **Simple Icons** (CC0, https://simpleicons.org), v11.0.0: `snowflake.svg`, `bigquery.svg`, `openai.svg`. Simple Icons ships single-colour marks, so each file's `fill` is set to the brand colour Simple Icons lists for it (#29B5E8, #669DF6, #412991).
