# Winapps website (V2)

The marketing site for Winapps (Winapps Software Solutions Pvt. Ltd.) at https://www.winapps.co.in: the new design with the WebGL ribbon, carrying over every page, URL and word of copy from V1.

Every page is pre-rendered static HTML with all its content in the source. JavaScript only enhances (header menus, search, contact form, the ribbon), and the ribbon is decoration that starts after first paint.

## Stack

- [Astro](https://astro.build) 7, static output (`trailingSlash: "always"`, one folder per page)
- Plain CSS with custom properties (`src/styles/global.css`), scoped `<style>` per component; no UI framework, no Tailwind
- Vanilla TypeScript, strict
- Self-hosted Inter / Inter Tight, images through `astro:assets` (AVIF/WebP)
- `@astrojs/sitemap` with real `<lastmod>` dates from git history

**Node.js >= 22.23** is required (Astro 7). CI uses Node 24.

## Commands

```sh
npm ci                # install
npm run dev           # local preview at http://localhost:4321/
npm run check         # astro check: types and templates, must be 0 errors / 0 warnings / 0 hints
npm run build         # production build into dist/
npm run preview       # serve dist/
npm run brand         # rebuild the logo and favicon set (only when the logo changes)
npm run indexnow      # ping IndexNow with the live sitemap (CI does this after each deploy)
```

Build-time settings (`SITE_URL`, `BASE_PATH`, `PUBLIC_WEB3FORMS_KEY`, `PUBLIC_PLAUSIBLE_DOMAIN`) are described in [DEPLOY.md](DEPLOY.md).

## Where the text lives

Edit content here; pages, JSON-LD, `llms.txt`, the Markdown page versions and the search index all read from the same sources, so they never disagree.

| What | Where |
| --- | --- |
| Company facts (name, legal name, phone, email, WhatsApp, founding year, regions), navigation, footer, contact-form options, promises, tech stack | `src/data/site.ts` |
| Page-level copy from V1, word for word (hero text, section headings, process, trust, engagement models, CTAs, labels) | `src/data/copy.ts` |
| The six services | `src/content/services/*.md` |
| Case studies | `src/content/work/*.md` |
| Blog guides and news posts (file names are the live URL slugs) | `src/content/blog/*.md`, `src/content/news/*.md` |
| FAQ (home and How we work) | `src/content/faq.yaml` |
| Industries | `src/content/industries.yaml` |
| Training tracks and courses | `src/content/training.yaml` |
| Testimonials, client logos, leadership (hidden until real, approved entries exist) | `src/content/testimonials/`, `clients/`, `team/` (copy `_TEMPLATE.md`) |
| Redirects from old winapps.co.in URLs | `src/lib/legacy-redirects.ts` |
| Ribbon look and motion (speed, breeze, gloss, wordmark, widths) | `RIBBON_CONFIG` in `src/scripts/ribbon.ts` |

Schemas in `src/content.config.ts` stop the build with a clear error if a field is missing. **Never add invented clients, testimonials, statistics, prices or dates.** Placeholders are marked `TODO(Winapps)` in the source.

## Code map

```
src/
  pages/        one file per route, plus the .md / .txt / .json endpoints
  layouts/      BaseLayout: head, canonical, Open Graph, JSON-LD, header, footer, ribbon canvas
  components/   Header (menus, search), Footer, PageHero, SectionHead, FaqList, CtaBand, Icon…
  styles/       global.css: design tokens and the shared classes (index in its header comment)
  lib/          url (href), seo (title/description limits), schema (JSON-LD), content (sorted collections), markdown
  scripts/      ribbon.ts (WebGL ribbon)
  data/         site.ts, copy.ts
  content/      editable content (Markdown / YAML)
public/         static files served as-is (icons, robots.txt, manifest, CNAME, IndexNow key)
scripts/        build-brand.mjs, indexnow.mjs
design-export/  the design spec (reference only, never shipped)
```

## SEO and AI-crawler files

| File | What it is |
| --- | --- |
| `public/robots.txt` | Allows search engines and AI search/assistant crawlers by name, then everyone; points to the sitemap |
| `/sitemap-index.xml` | Generated by `@astrojs/sitemap` (config in `astro.config.mjs`) |
| `src/pages/llms.txt.ts` → `/llms.txt` | [llmstxt.org](https://llmstxt.org) summary: who Winapps is, and every key page with its Markdown version |
| `src/pages/llms-full.txt.ts` → `/llms-full.txt` | The full text of the main pages in one file, each with its source URL |
| `src/pages/**/*.md.ts` → `/<page>.md` | A clean Markdown twin of each key page: `/` → `/index.md`, `/about/` → `/about.md`, `/services/ai-ml/` → `/services/ai-ml.md`, `/training/python/` → `/training/python.md`. Pages advertise theirs with `<link rel="alternate" type="text/markdown">` |
| `src/lib/markdown.ts` | The builders behind all of the above |
| `src/pages/search.json.ts` → `/search.json` | Index for the header search dialog |
| `src/lib/schema.ts` | JSON-LD: Organization + ProfessionalService, WebSite, WebPage, BreadcrumbList, Service, Course, FAQPage, Article |
| `public/.well-known/security.txt` | RFC 9116 security contact (renew `Expires` before 2027-10-29) |
| `public/site.webmanifest` | Web app manifest and icons |
| `public/<key>.txt`, `scripts/indexnow.mjs` | IndexNow key and the script CI runs after each deploy |
